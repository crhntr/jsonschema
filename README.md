# jsonschema

A spec-compliant JSON Schema toolkit for Go, built on `encoding/json/v2`.

## Vision

- **Code generation** — turn JSON Schema documents into idiomatic Go types.
- **Validation CLI** — validate JSON documents against a schema from the command line.
- **Library** — use the same primitives directly from Go code.

## Status

Early development. APIs will change.
